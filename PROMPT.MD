# User Prompt for Claude Code

An interactive web-app that can be published to github pages with minimal configuration.

Create a web-app that can:

Drag-and drop logic gates with inputs, and outpus
Drag-and drop dispalys, "lightbulbs", which show the output, be able to see wire connections and wire on/off by the color of the wire.
Drag-and drop input things like switches or a number pad that outputs the selected number in binary,
Be able to save the lcoations, states, and components into a file or locally when re-opened,
Be able to export a professional schematic or diagram as a png or svg (only when everything else is done and functional)

Leave all testing to me. If there is a server involved, start the server and keep it on. Restart it when nessecary.
